# MelodyV3 - 三源聚合音乐播放器

一个现代化的桌面音乐播放器，聚合酷狗、网易云、B站三大音乐平台。

## 功能特性

### 核心功能
- **三源聚合搜索** - 同时搜索酷狗、网易云、B站，结果按来源分组排序，支持分页加载
- **智能播放** - 自动获取最佳播放链接，失败时自动切换其他源（Fallback），全部失败自动切下一首
- **播放队列** - 点击歌曲即加入队列播放，队列面板支持拖拽排序、移除、清空，"下一首播放"随时插入
- **歌词同步** - 逐字渐变高亮显示（支持酷狗逐字歌词时间戳），自动滚动，支持歌词偏移调节
- **歌词翻译** - 自动显示网易云翻译歌词（如有），可一键开关
- **多歌单管理** - 任意创建/重命名/删除歌单，封面网格视图，歌单内拖拽排序，导入/导出 JSON
- **收藏 ♥** - 一键收藏喜欢的歌曲，侧边栏直达"我喜欢的音乐"

### 界面设计
- **现代化 UI** - 毛玻璃效果，语义化设计 token，深浅双主题
- **深色/浅色/跟随系统** - 三种主题模式一键切换，偏好自动保存
- **封面主题色自适应** - 播放歌曲时从封面提取主色调，界面颜色跟随变化（可关闭）
- **全屏歌词 v2** - 沉浸式歌词体验：
  - Apple Music 式三段排版（当前句居中大字号 + 前后句小字淡出）
  - 逐字卡拉OK 高亮（酷狗逐字时间戳，回退智能均分）
  - 三种背景模式：纯净 / 频谱 / 星空（粒子星尘）
  - 可滚动浏览歌词、点击任意行跳转、点击空白播放/暂停
  - Ctrl+滚轮调节字号，控制条自动隐藏

### 交互优化
- **快捷键支持**
  - `空格` - 播放/暂停
  - `←/→` - 快退/快进 5 秒（`Ctrl+←/→` 切歌）
  - `↑/↓` - 调节音量
  - `M` - 静音切换
  - `L` - 歌词面板切换
  - `F` - 全屏歌词
  - `Esc` - 关闭全屏/菜单
- **鼠标操作**
  - 点击/拖拽进度条跳转（拖拽时音频不中断）
  - 滚轮调节音量（悬停音量区域）
  - 歌曲行 hover 快捷按钮（收藏/更多）
- **右键菜单** - 播放、下一首播放、添加到歌单（多歌单选择）、上移/下移、从歌单移除、复制歌名、复制播放链接
- **歌单拖拽排序** - 歌单内歌曲、播放队列均支持拖拽调整顺序
- **搜索历史** - 自动记录最近 10 条搜索，点击快速重搜
- **重启续播** - 自动记忆上次播放的歌曲与进度（24 小时内有效）

### 播放模式
- 顺序播放 / 列表循环 / 单曲循环 / 随机播放（偏好记忆）

### 倍速播放
- 支持 0.5x、0.75x、1x、1.25x、1.5x、2x

### 音频增强
- 切歌渐入渐出（0.2s），过渡更自然
- Web Audio API 频谱可视化（底部波形 + 全屏歌词动效）

## 安装使用

### 直接运行
1. 从 [GitHub Release](https://github.com/XiaoHan-612/MelodyV3/releases/latest) 下载最新版 `MelodyV3.exe`（免安装；Release 由 CI 自动构建，仓库不保存二进制）
2. 双击运行即可（依赖系统自带的 WebView2 运行时）

### 从源码编译
```bash
# 前置要求：Go 1.22+、Node.js 18+、Git
git clone https://github.com/XiaoHan-612/MelodyV3.git
cd MelodyV3
build.bat   # 自动安装依赖并完成前端打包 + Go 编译
```

## API 接口

### 搜索音乐
```
GET /api/search?keyword={关键词}&source={来源}&page={页码}
```
- `keyword`: 搜索关键词（必填）
- `source`: 音乐源（kg/ne/bl，可选，默认全部并发搜索）
- `page`: 页码（可选，默认 1，每页 20 条）

### 获取播放链接（带自动切源）
```
GET /api/song/url?id={歌曲ID}&source={来源}
```

### 获取歌词（含逐字歌词）
```
GET /api/song/lyric?id={歌曲ID}&source={来源}
```
返回 `{lrc, tlrc, qrc}`，其中 `qrc` 为酷狗逐字歌词时间戳（如可用）。

### 按歌名搜索歌词（跨平台匹配）
```
GET /api/song/lyric/search?title={歌名}&artist={歌手}
```

### 多歌单管理
```
GET  /api/playlists        # 获取全部歌单
POST /api/playlists        # 全量保存歌单库（JSON body）
```
歌单数据统一保存在 `%APPDATA%\MelodyV3\playlists.json`（v4.0 及更早的主目录旧数据会自动迁移，原文件保留）。

### 版本 / 日志
```
GET /api/version        # 当前版本号（CI 构建注入）
```

## 常见问题

### Q: 为什么有些歌曲无法播放？
A: 可能是版权限制或链接失效，程序会自动尝试其他源；全部失败时自动切到下一首。

### Q: 歌词不同步怎么办？
A: 点击歌词面板的 `-0.5s` / `+0.5s` 按钮手动调节偏移。

### Q: 如何备份我的数据？
A: 设置 → 关于 → "导出全部数据"可一键导出歌单+收藏+最近播放的 JSON 备份；歌单文件本身在 `%APPDATA%\MelodyV3\playlists.json`；遇到问题可在设置里"打开日志目录"把日志发给开发者。

### Q: 封面颜色没变化？
A: 部分歌曲封面跨域受限或颜色太灰（饱和度低），会自动使用默认蓝色；也可以在设置中关闭封面主题色。

### Q: 旧版本的歌单还在吗？
A: 首次启动 v4.1 会自动把旧位置（主目录点文件）的数据迁移到 `%APPDATA%\MelodyV3\`，旧文件保留不删除。
